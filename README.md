## Featured project

### [Smart Attendance System](https://github.com/theamanlab/smart-attendance-system)
A webcam-based attendance prototype using **YuNet face detection**, **SFace embeddings**, and **cosine-similarity matching**.

- Enroll people from local photos and build reference embeddings.
- Recognize enrolled faces through a Tkinter interface or an OpenCV window.
- Record attendance in CSV with a per-person, per-date duplicate check.
- Keep face photos, embeddings, and attendance records outside version control.

**Stack:** Python · OpenCV · NumPy · Pillow · Tkinter  
**Status:** Educational prototype; recognition performance has not yet been benchmarked.

[Explore the code and setup](https://github.com/theamanlab/smart-attendance-system#readme) · [Evaluation plan](https://github.com/theamanlab/smart-attendance-system/blob/main/docs/EVALUATION.md)
